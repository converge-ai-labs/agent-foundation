# Glossary

One word, one meaning. If a new word is needed, add it here first. Definitions are short; the linked section owns the rule.

## Tenancy

| Word             | Meaning                                                                                                                              | Not                                                       |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------- |
| **organization** | the administration boundary that holds workspaces, members and shared provider resources ([03](03-tenancy.md))                       | a Console-only tenant                                     |
| **workspace**    | the resource and work boundary inside an organization                                                                                | a directory, a sandbox                                    |
| **principal**    | a user or a service account; what grants and credentials attach to                                                                   | an actor in the audit sense only                          |
| **credential**   | what proves a request is a principal: a password, an API key or a token                                                              | a provider's secret (that is a `credential` column)       |
| **API key**      | a bearer credential of a user or service account, always confined to one workspace; its principal's current grants within that scope | an organization-wide key, a grant of administrator rights |
| **token**        | a short-lived secret looked up by hash: a login session, a password-reset link or an email-change link                               | an API key, an OAuth token                                |
| **grant**        | a role given to a principal in an organization or a workspace                                                                        | a role binding                                            |
| **role**         | a named set of verbs; four built-ins plus distribution definitions ([03](03-tenancy.md#roles-and-grant-sources))                     | a permission, an action, a process role                   |
| **verb**         | `read`, `run`, `write` or `admin`; what `authorize` checks                                                                           | an operation name                                         |
| **authority**    | a run's persisted execution ceiling, intersected with its principal's current grants ([03](03-tenancy.md#execution-authority))       | the worker's own credentials                              |

## Resources

| Word                     | Meaning                                                                                                                                                                                     | Not                                                    |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| **resource**             | anything a tenant configures under `resources/`: agents, skills, provider resources, models, templates, connections, secrets, assets, subscriptions ([04](04-resources.md))                 | a run, a thread, an HTTP resource in general           |
| **revisioned**           | the lifecycle of agents and skills: an archivable head with immutable numbered revisions that runs freeze ([04](04-resources.md#two-lifecycles))                                            | versioned by ETag                                      |
| **live**                 | the lifecycle of every other mutable resource: one row, resolved and authorized at each use                                                                                                 | cached                                                 |
| **head** (of a resource) | the mutable row of a revisioned resource: identity, metadata, archive state and the default revision                                                                                        | a thread's head run                                    |
| **revision**             | an immutable, numbered configuration of a revisioned resource                                                                                                                               | a version, a generation, a draft                       |
| **pin**                  | the exact revision a skill or subagent edge resolves to when a configuration is validated ([04](04-resources.md#validation))                                                                | a default, which can change                            |
| **override**             | a run's changes to its revision's configuration, validated like a revision and frozen with the run                                                                                          | a new revision                                         |
| **Agent Composer**       | the builtin agent that creates agents and revisions through the `configuration` toolset ([04](04-resources.md#agent-composer))                                                              | a draft editor, a separate session kind                |
| **provider resource**    | a tenant-configured backend account with `type`, `config`, write-only credential and enabled state: model, environment, connector, web or memory ([04](04-resources.md#provider-resources)) | an adapter, a live client                              |
| **model**                | one upstream model served by one model provider resource                                                                                                                                    | a model provider, a calling API                        |
| **template**             | the live configuration managed environments are created from; an instance keeps the recipe it was created with ([04](04-resources.md#environment-templates))                                | an agent template, a revisioned resource               |
| **connection**           | a source of tools with one credential: a Remote MCP server or one account of a connector app ([04](04-resources.md#connections))                                                            | a network connection                                   |
| **connector provider**   | a hosted integration platform, such as Composio, configured once, through which connections bind app accounts                                                                               | a connection, a tool                                   |
| **authorization**        | the flow that obtains a connection's credential: OAuth or a connector's hosted account setup                                                                                                | the act of authorizing a request (that is `authorize`) |
| **operation**            | one external action with a durable identity and a known or unknown outcome: a connection's remote step or an environment's lifecycle step                                                   | permission to repeat after a timeout                   |
| **generation**           | an environment's monotonic counter whose advance invalidates an outstanding lifecycle operation's result                                                                                    | an attempt number, a resource version                  |
| **caller headers**       | a thread's `mcp_headers`: header values per MCP connection, frozen into each run at acceptance ([04](04-resources.md#caller-headers))                                                       | authentication, a tool grant, a per-message option     |
| **secret**               | an opaque value a tenant stores and never reads back; used by tools through the requirement keys their agent declares ([04](04-resources.md#secrets))                                       | a provider credential, a signing secret                |
| **credential** (column)  | the encrypted, write-only secret of a provider resource or connection; an OAuth connection keeps its grant's tokens separately, in `tokens`                                                 | a tenancy credential                                   |
| **upload**               | staged bytes bound to one workspace by a receipt, used to create skills and assets                                                                                                          | an asset                                               |
| **asset**                | immutable content with metadata, referenced by ID from input and output                                                                                                                     | a file in an environment                               |
| **subscription**         | a webhook: lifecycle kinds, filter, URL and signing secret                                                                                                                                  | a hook, a stream subscriber                            |

## Runs

| Word                   | Meaning                                                                                                                                                                 | Not                                                                     |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| **session**            | a group of threads; one conversation in the Console                                                                                                                     | a login session (a `session` token), a database session                 |
| **thread**             | one independently advancing history; owns its inbox, mounts and caller headers ([05](05-runs.md))                                                                       | a conversation, an OS thread                                            |
| **inbox**              | a thread's queued input, selected by state eligibility then position; pending and assigned entries occupy its capacity                                                  | an unconditional FIFO, a place for answers to a wait                    |
| **entry**              | one inbox row: a message or a child result                                                                                                                              | a steer or a queued submission (those are `delivery` values), an answer |
| **payload**            | an entry's typed content, selected by its `kind` and stored inline within its bound; files are assets referenced by ID                                                  | a second execution state, an untyped JSON bag                           |
| **delivery**           | how an entry reaches a running run: `steer` now or `next_run`                                                                                                           | webhook delivery (that is an outbox row)                                |
| **offered**            | a worker-local fact that an entry was given to this attempt's Harness run; never a durable status                                                                       | consumed                                                                |
| **incorporated**       | an offered entry that a checkpointed Harness state contains                                                                                                             | acknowledged by enqueueing, observed in an event                        |
| **assigned**           | an entry bound to one run, surviving attempt replacement                                                                                                                | incorporated, successful                                                |
| **consumed**           | an entry whose incorporation was committed with a checkpoint pointer                                                                                                    | proof that the run succeeded                                            |
| **submit**             | append an entry to a thread's inbox and try to accept                                                                                                                   | start                                                                   |
| **accept**             | select a queued entry for a thread and call `start_run` with it                                                                                                         | submit, resume                                                          |
| **start_run**          | the only function that creates a run; every creation path calls it                                                                                                      | accept, submit                                                          |
| **run**                | one accepted advancement of a thread with one agent revision                                                                                                            | an attempt, a Harness run                                               |
| **current run**        | the thread's run in `accepted` or `running`                                                                                                                             | the head                                                                |
| **head** (of a thread) | the thread's latest completed or waiting run, which the next run continues                                                                                              | the current run, a failed run, a resource head                          |
| **claim**              | a worker taking an accepted run and creating an attempt                                                                                                                 | scheduling                                                              |
| **attempt**            | one fenced execution of a run by one worker                                                                                                                             | a retry                                                                 |
| **lease**              | a worker's time-bounded right to execute an attempt, renewed by heartbeat                                                                                               | a fence                                                                 |
| **fence**              | the current attempt identity plus the worker, token, status and unexpired-lease predicate every execution write proves                                                  | a lock, a lease                                                         |
| **execute**            | running the Harness for an attempt                                                                                                                                      | process, drive                                                          |
| **boundary**           | the moment between one model request and the next, where the worker commits a checkpoint and reads the inbox                                                            | a turn                                                                  |
| **checkpoint**         | resumable Harness state in an immutable object, made durable by the fenced transaction that moves `runs.checkpoint` to it and consumes incorporated input               | a display object, a database savepoint                                  |
| **display**            | the run's folded display items in an immutable object committed with each checkpoint                                                                                    | the stream, a projection of the message history                         |
| **pointer**            | a typed run column (`checkpoint`, `display`) naming the committed object; the only thing that makes run objects reachable                                               | an object key alone, a cursor                                           |
| **seal**               | the transaction that records a terminal outcome or a wait, or yields the attempt; successor and parent work follows durably                                             | commit, finalize                                                        |
| **recovery**           | a replacement attempt that restores the run's committed checkpoint and cleans its object prefix before continuing                                                       | resubmission of the input, reversal of a seal                           |
| **resume**             | the run operation that answers a waiting run's approvals and client-tool requests, closes its questions without a response, and starts its successor ([05](05-runs.md)) | an inbox entry, a retry                                                 |
| **answer**             | one resume result identified by `tool_call_id`: an approval decision or a client-tool result                                                                            | ordinary text replying to a question                                    |
| **approval**           | a decision required before a specific tool call may execute                                                                                                             | a question asked through `ask_user_question`                            |
| **client tool**        | a tool whose result an external client supplies through resume                                                                                                          | an unanswered question                                                  |
| **user input wait**    | a pending `ask_user_question` call; a message continues a question-only wait, and resume closes it without a response                                                   | an approval                                                             |
| **call ID**            | the identity of one paid external call, shared by the admission check and its usage records                                                                             | a new ID on usage redelivery                                            |
| **dispatch check**     | the check every tool call passes before it is sent: cancellation, lease, limits and admission ([08](08-providers.md#tool-sources))                                      | a tool permission                                                       |

## Environments

| Word               | Meaning                                                                          | Not                                              |
| ------------------ | -------------------------------------------------------------------------------- | ------------------------------------------------ |
| **environment**    | a sandbox instance a thread mounts, possibly shared ([06](06-environments.md))   | a template, a provider, a deployment environment |
| **mount**          | one environment attached to a thread under a name                                | a live mount, a memory mount                     |
| **desired mount**  | a thread's selection for future runs                                             | evidence of current use                          |
| **accepted mount** | a run's frozen mount, which pins active use while the run is accepted or running | separate environment ownership                   |

## Memory

| Word                     | Meaning                                                                                                                                           | Not                                        |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| **memory**               | a workspace resource that agents read and write across conversations: a file memory or a record memory ([11](11-memory.md))                       | a run's history, the Harness context       |
| **file memory**          | a memory of kind `file` and type `postgres`: a tree of text files the Service stores with their history                                           | a record memory, an environment's files    |
| **record memory**        | a memory of kind `record`: short text records recalled by similarity, kept in a Memory Provider's backend under the memory's namespace            | a file memory, a usage record              |
| **Memory Provider**      | a provider resource of kind `memory`, an account of a record memory backend such as mem0 ([11](11-memory.md#memory-providers))                    | the Service's file store                   |
| **namespace**            | the part of a Memory Provider's backend one record memory owns, such as a mem0 `user_id`; purged through the outbox when the memory is deleted    | a workspace, a key                         |
| **recall**               | records closest to a run's first input, added to it as untrusted data for each record memory mounted with `recall` on                             | a memory's context, a search tool          |
| **memory mount**         | a memory attached to a thread under a name with `read` or `write` access; each run freezes its thread's memory mounts ([11](11-memory.md#mounts)) | an environment mount                       |
| **guide**                | the owner's guidance on what belongs in a memory and how it is organized, placed in a run's instructions                                          | memory content, a skill                    |
| **always-loaded file**   | a path the memory's owner names in `always_load`, whose content leads the memory's context in every thread                                        | a pinned file an agent chooses             |
| **memory file revision** | the content one change of a memory file replaced, with the change's attribution                                                                   | an agent or skill revision, a file version |
| **change feed**          | a memory's changes numbered without gaps, which lists the paths changed after a position                                                          | an event stream, the outbox                |
| **memory cursor**        | a run's position in a memory's change feed up to which its history holds that memory's context ([11](11-memory.md#execution))                     | a list cursor, a pointer                   |

## Facts, delivery and runtime

| Word               | Meaning                                                                                                                                       | Not                                                |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| **usage record**   | one immutable Harness usage report with its model and price snapshot ([07](07-facts-and-delivery.md#usage-records))                           | a cost ledger, a budget                            |
| **lifecycle kind** | the name of a run or attempt status transition, such as `run.completed`, that a subscription selects                                          | a stored event log, a stream entry, an audit event |
| **stream**         | the bounded, provisional Redis feed of one thread's output and boundary markers ([07](07-facts-and-delivery.md#the-thread-stream))            | durable output, the display                        |
| **outbox**         | durable delivery intents: webhooks, child results and identity mail ([07](07-facts-and-delivery.md#outbox))                                   | an event log, object reclamation                   |
| **sweep**          | a periodic background function that finds its work by a `WHERE` clause ([09](09-runtime.md#sweeps))                                           | a job, a reconciler                                |
| **wake marker**    | the single Redis list entry that makes an idle worker scan sooner; it carries no run                                                          | a task, a claim                                    |
| **infra**          | shared database, storage, transport, audit, outbox and scheduling mechanisms under `infra/`, without business-package dependencies            | assembly, a home for business handlers             |
| **role** (process) | `all`, `control` or `worker` ([09](09-runtime.md#roles))                                                                                      | a tenancy role                                     |
| **distribution**   | typed contributions to assembly: routers, tables, migrations, settings, sweeps, providers, roles, grant sources, authentication and admission | an edition, a plugin                               |

## Providers

| Word                    | Meaning                                                                                                                                                             | Not                                     |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| **provider definition** | the Harness's description of one backend type: schemas, authentication, capability flags and factory, registered by `(kind, type)` ([08](08-providers.md#registry)) | a tenant-configured resource            |
| **registry**            | the deployment's provider definitions by kind and type                                                                                                              | a catalogue of tenant accounts          |
| **provider handle**     | a runtime backend object built from plain values and a revealed credential for one use; its caller owns its lifetime                                                | a database row, a registered definition |
| **endpoint policy**     | the deployment's rules for which hosts and addresses outbound requests may reach ([08](08-providers.md#outbound-endpoint-policy))                                   | a firewall, a per-tenant allow list     |
| **trace backend**       | the operator-configured Langfuse or Logfire project that receives exported spans and answers trace queries                                                          | a provider resource, a registry kind    |
| **installed plugin**    | a Harness plugin factory the deployment installs by entry-point key, which agents select with their own configuration                                               | a provider, a distribution              |
