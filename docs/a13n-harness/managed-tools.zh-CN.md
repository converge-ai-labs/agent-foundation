---
title: 受管工具
description: 在 Harness 中强制执行工具权限、Shell 命令安全审查与人工审批工作流。
---

受管工具允许宿主在不修改工具实现的前提下，决定每次工具调用是自动放行、暂停等待人工审批还是直接拒绝。

## 选择工具权限

在能力或宿主策略中配置权限规则，将工具调用分为三种结果：

| 决策    | 行为                                           |
| ------- | ---------------------------------------------- |
| `allow` | 立即执行                                       |
| `ask`   | 暂停运行并产出延迟审批请求，交由宿主或用户决策 |
| `deny`  | 拒绝调用，并将拒绝原因返回给模型               |

运行因审批暂停时，读取 `result.deferred`、收集用户决策并传入审批结果恢复运行。完整流程见[人机协作](human-in-the-loop.md)。

## Shell 命令审查

添加 `ShellReviewCapability`，在执行 `environment.shell_exec` 前由专用审查模型评估风险：

- 输出风险等级（`low`、`medium`、`high`、`extra_high`）与简短说明。
- 达到或超过 `ask_at_or_above` 阈值的命令会附带审查结论暂停等待人工审批。
- 拒绝原因会反馈给智能体，便于其提出更安全的替代命令。

## 后台与保留工具执行

耗时工具（例如基于进程的 Shell 命令）可在前台等待超时后返回句柄，让智能体通过 `shell_info`、`shell_wait` 或取消操作异步管理，避免阻塞整轮交互。
