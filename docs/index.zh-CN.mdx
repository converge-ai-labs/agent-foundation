<Intro title="Agent Foundation (a13n)" action={{ text: "选择适合的路径", href: "/overview/choose-your-path/" }}>

在您自主可控的基础设施上构建、运行与扩展 AI Agent。无论您是需要在 Python 微服务中内嵌灵活的 Agent 运行时，还是想在代码仓库中通过终端与 Web 界面与 Agent 并肩编码，亦或是为全公司部署支持多租户与长期记忆的企业级 Agent 托管平台，Agent Foundation 都能提供扎实、模块化的系统基石。

</Intro>

<RuntimeMap alt="Console 与 SDK/HTTP 客户端连接到 Service API。control 节点将持久化状态写入 PostgreSQL，worker 节点认领 run 并通过内嵌的 Harness 执行，同时将执行检查点保存至对象存储。租约过期后，后续重试将基于保存的检查点无缝恢复。Harness UI 和 Python 应用程序亦可直接独立内嵌 Harness。" />
