<Intro title="Agent Foundation" action={{ text: "选择使用方式", href: "/overview/choose-your-path/" }}>

面向 AI agent 的开源自托管基础。你可以部署托管式 Service，将 Harness 库嵌入应用，或使用 Harness UI 进行交互式工作。

</Intro>

<ArchitectureOverview alt="a13n Service 与 Harness 的架构概览：通过 SDK、HTTP API、Console 和 Harness UI 使用，并连接执行环境、记忆、模型、Web 数据和 MCP 连接。" />

<Section title="产品">
<Products>
<Product icon="service" title="Service" audience="团队与应用" href="/a13n-service/" start="/a13n-service/get-started/">

自托管平台，提供身份管理、工作空间、持久执行和会话保存，可通过 Console 或 HTTP API 使用。

</Product>
<Product icon="harness" title="Harness" audience="Python 开发者" href="/a13n-harness/" start="/a13n-harness/getting-started/">

将指令、工具和能力组合成 agent，并在你的进程中运行的库。存储和访问控制由你的应用负责。

</Product>
<Product icon="harness-ui" title="Harness UI" audience="个人与小团队" href="/a13n-harness-ui/" start="/a13n-harness-ui/setup/">

在代码仓库中与 agent 协作的终端和浏览器工作台，可共享对话、文件和终端。

</Product>
</Products>
</Section>
