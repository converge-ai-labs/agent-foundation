<Intro title="Agent Foundation (a13n)" action={{ text: "选择适合你的路径", href: "/overview/choose-your-path/" }}>

在自有基础设施上构建、运行和运维 AI agent。你可以将 agent 执行引擎直接嵌入 Python 应用，在终端或浏览器中与 agent 协同开发，或者为团队部署共享平台——在 Console 中配置并调试 agent，再通过 SDK 或 HTTP API 接入业务系统。

</Intro>

<RuntimeMap alt="Console 和使用 SDK 或 HTTP API 的应用连接到 Service。control 角色将工作写入 PostgreSQL，worker 领取 run 后通过 Harness 执行，并将检查点保存到对象存储。租约过期后，后续尝试可以从已保存的检查点继续执行。Harness UI 和 Python 应用也可以直接嵌入 Harness。" />

<Section title="核心产品">
<Products>
<Product icon="service" title="Service" audience="平台工程师与团队管理员" href="/a13n-service/" start="/a13n-service/get-started/">

自托管的多租户 agent 运行平台。支持在 Console 中可视化配置或用 Agent Composer 生成 agent，统一治理工作空间权限与外部凭证，编排周期性定时任务，维护团队共享的 Memory Spaces，并在客户端断线后保持后台任务持续运行。

</Product>
<Product icon="harness" title="Harness" audience="Python 开发者" href="/a13n-harness/" start="/a13n-harness/getting-started/">

可嵌入的 Python agent SDK。通过指令、Python 类型化工具、MCP 服务、子 Agent 委派与 CodeAct 组装 agent，由你的宿主应用自主掌控状态存储、权限策略与结果分发。

</Product>
<Product icon="harness-ui" title="Harness UI" audience="开发者与 DIY 玩家" href="/a13n-harness-ui/" start="/a13n-harness-ui/setup/">

面向代码仓库的终端与浏览器交互工作台。支持读写代码、实时引导运行中的任务、开启 Live 语音模式对话，并通过 Markdown 子角色、Skill 和 Content Plugin 自由定制你的开发流。

</Product>
</Products>
</Section>
