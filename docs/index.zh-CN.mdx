<Intro title="Agent Foundation" action={{ text: "选择使用方式", href: "/overview/choose-your-path/" }}>

使用执行基础 Harness 构建和运行 agent。通过 Harness UI，在终端或浏览器中与 agent 协作。团队或应用需要托管访问和持久执行时，部署 Service。

</Intro>

<ArchitectureOverview alt="Service 与 Harness 的架构概览：通过 SDK、HTTP API、Console 和 Harness UI 使用，并连接执行环境、记忆、模型、Web 数据和 MCP 连接。" />

<Section title="产品">
<Products>
<Product icon="service" title="Service" audience="团队与应用" href="/a13n-service/" start="/a13n-service/get-started/">

为团队或应用部署 agent。Service 管理身份、工作空间、对话和持久执行；通过 Console 或 HTTP API 提交任务。

</Product>
<Product icon="harness" title="Harness" audience="Python 开发者" href="/a13n-harness/" start="/a13n-harness/getting-started/">

用指令、工具和能力组合 agent，在 Python 进程中运行。存储、访问控制和结果交付由你的应用负责。

</Product>
<Product icon="harness-ui" title="Harness UI" audience="个人与可信小团队" href="/a13n-harness-ui/" start="/a13n-harness-ui/setup/">

连接模型，在代码仓库中与 agent 协作。终端和浏览器界面在同一个可信实例内共享对话、文件和终端。

</Product>
</Products>
</Section>
