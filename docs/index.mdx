<Intro title="Agent Foundation" action={{ text: "Choose your path", href: "/overview/choose-your-path/" }}>

Build and run agents with Harness, the execution foundation. Use Harness UI to work with agents in a terminal or browser. Deploy Service when your team or application needs managed access and durable execution.

</Intro>

<ArchitectureOverview alt="Service and Harness connect SDKs, the HTTP API, Console, and Harness UI with environments, memory, models, web data, and MCP connections." />

<Section title="Products">
<Products>
<Product icon="service" title="Service" audience="Teams and applications" href="/a13n-service/" start="/a13n-service/get-started/">

Deploy agents for a team or application. Service manages identities, workspaces, conversations, and durable execution; use Console or the HTTP API to submit work.

</Product>
<Product icon="harness" title="Harness" audience="Python developers" href="/a13n-harness/" start="/a13n-harness/getting-started/">

Compose an agent from instructions, tools, and capabilities, then run it in your Python process. Your application controls storage, access, and result delivery.

</Product>
<Product icon="harness-ui" title="Harness UI" audience="Individuals and trusted small teams" href="/a13n-harness-ui/" start="/a13n-harness-ui/setup/">

Connect a model and work with an agent in your repository. The terminal and browser interfaces share conversations, files, and terminals within a trusted instance.

</Product>
</Products>
</Section>
