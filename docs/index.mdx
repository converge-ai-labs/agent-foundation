<Intro title="Agent Foundation (a13n)" action={{ text: "Choose your path", href: "/overview/choose-your-path/" }}>

Build, run, and operate AI agents on your own infrastructure. Embed agent execution directly inside a Python application, work with an interactive agent in your terminal or browser, or deploy a shared platform where your team configures agents in Console and calls them over an SDK or HTTP API.

</Intro>

<RuntimeMap alt="Console and SDK or HTTP clients connect to the Service API. The control role persists work in PostgreSQL. A worker leases a run, executes it with Harness, and saves checkpoints to object storage. A later attempt can resume from a saved checkpoint after lease expiry. Harness UI and Python applications can also embed Harness directly." />

<Section title="Products">
<Products>
<Product icon="service" title="Service" audience="Platform engineers & team admins" href="/a13n-service/" start="/a13n-service/get-started/">

Self-hosted, multi-tenant agent platform. Build agents visually or with Agent Composer, govern workspace roles and credentials, schedule recurring runs, organize shared Memory Spaces, and keep accepted work running when clients disconnect.

</Product>
<Product icon="harness" title="Harness" audience="Python developers" href="/a13n-harness/" start="/a13n-harness/getting-started/">

Embeddable Python agent SDK. Compose an agent from instructions, typed Python tools, MCP servers, subagents, and CodeAct, while your application controls storage, access policy, and result delivery.

</Product>
<Product icon="harness-ui" title="Harness UI" audience="Developers & DIY builders" href="/a13n-harness-ui/" start="/a13n-harness-ui/setup/">

Interactive terminal and browser workbench for codebases. Inspect files, steer active work, talk through tasks in Live voice mode, and extend your workflow with Markdown subagents, Skills, and Content Plugins.

</Product>
</Products>
</Section>
