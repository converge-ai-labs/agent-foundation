<Intro title="Agent Foundation (a13n)" action={{ text: "Choose your path", href: "/overview/choose-your-path/" }}>

Build, run, and scale AI agents on your own infrastructure. Whether you want to embed a flexible agent runtime in your Python service, collaborate with an agent directly in your codebase via terminal or browser, or deploy a full multi-tenant agent execution platform for your organization, Agent Foundation provides the modular building blocks you need.

</Intro>

<RuntimeMap alt="Console and SDK or HTTP clients connect to the Service API. The control role persists work in PostgreSQL. A worker leases a run, executes it with Harness, and saves checkpoints to object storage. A later attempt can resume from a saved checkpoint after lease expiry. Harness UI and Python applications can also embed Harness directly." />

<Section title="Product suite">
<Products>
<Product icon="harness" title="Harness" audience="Python developers" href="/a13n-harness/" start="/a13n-harness/getting-started/">

Embed type-safe agent execution directly in your Python application. Define instructions, compose Python and MCP tools, handle human-in-the-loop interactions, and preserve durable conversation state across restarts.

</Product>
<Product icon="harness-ui" title="Harness UI" audience="Developers & DIY builders" href="/a13n-harness-ui/" start="/a13n-harness-ui/setup/">

Interactive workbench featuring both a rich terminal interface and a collaborative WebUI. Work directly on codebases, coordinate multi-agent delegations, speak in real time with Live voice mode, and extend capabilities with custom Skills and Content Plugins.

</Product>
<Product icon="service" title="Service" audience="Platform engineers & team admins" href="/a13n-service/" start="/a13n-service/get-started/">

Self-hosted, multi-tenant agent execution platform. Manage access with fine-grained RBAC, build agents visually with Agent Composer, schedule periodic cron jobs, connect enterprise MCP integrations, and maintain long-term team memory.

</Product>
</Products>
</Section>
