Each operation page lists its parameters, request body, responses, and request examples; the navigation groups the pages by API area. [HTTP conventions](../http.md) explain authentication, preconditions, idempotency keys, paging, and errors, which apply to every operation.

To generate a client or import the API into another tool, download [the complete OpenAPI JSON](/reference/service-openapi.json). It describes the Service version built from `main`; a running Service publishes its own document at `/api/v1/openapi.json`.
