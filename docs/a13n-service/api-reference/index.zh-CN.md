每个操作页面列出参数、请求体、响应和请求示例；导航按 API 领域对页面分组。[HTTP 约定](../http.md)介绍适用于所有操作的认证、前置条件、幂等 key、分页和错误。

要生成客户端或将 API 导入其他工具，请下载[完整的 OpenAPI JSON](/reference/service-openapi.json)。它描述从 `main` 构建的 Service 版本；运行中的 Service 在 `/api/v1/openapi.json` 发布自己的文档。
