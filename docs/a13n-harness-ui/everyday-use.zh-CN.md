**Harness UI 终端界面（TUI）**专为常驻终端的高效开发者量身定制。它将前沿大语言模型与本地 Shell 流畅融合，让您在无需频繁切换窗口的前提下，随心审查代码、分析 Git 提交并执行构建命令。

## 日常交互

完成[初始化设置](setup.md)后，在任意代码仓库根目录下直接启动：

```bash
a13n-harness-ui
```

1. 输入 `/status` 验证当前激活的 Agent、默认 Model 以及所在的工作空间路径。
2. 键入任务提示词（例如：`审查最近的三次提交，并解释现有的单元测试覆盖策略。`）并按下回车。
3. 实时阅读流式回复。随时按下 **Ctrl+O** 展开查看完整的工具执行入参、终端输出以及 Git Diff 变更。
4. 在当前会话线程中继续追问，或输入 `/new` 开启全新独立任务。

底部输入框会根据系统当前的运行状态自适应调整回车键的行为：

| 当前运行状态 | 按下 Enter 执行的操作 |
| :--- | :--- |
| **空闲（Idle）** | 将草稿内容作为新一轮任务正式提交 |
| **Agent 生成中（Working）** | 将输入作为实时引导（Steering）即刻注入当前执行流 |
| **决策卡片打开（Decision open）** | 确认并提交当前审批或提问卡片中所选的决策项 |

按下 **Ctrl+J** 或 **Alt+Enter** 可在输入框中换行，也支持直接粘贴多行文本。

如果需要借助惯用编辑器撰写复杂的长篇 Prompt，可在输入框中随时按下 **Ctrl+G**。Harness UI 将自动唤起系统的 `$VISUAL` 或 `$EDITOR`（如 `nvim` 或 `code --wait`）。在熟悉的编辑器中随心修改保存并关闭后，内容会自动无缝回填至输入框。

### 选择 Agent 或 Model

在终端中快速查看或动态切换模型与智能体：

| 操作目标 | 命令 | 执行效果 |
| :--- | :--- | :--- |
| **切换 Agent** | `/agent <agent-id>` | 即刻更换系统提示词、启用的 Capabilities、工具集与子角色 |
| **切换 Model** | `/model <model-id>` | 切换活跃模型提供方；并将选择偏好记忆在当前项目中 |
| **重置 Model** | `/model default` | 清除临时偏好，恢复项目配置中声明的默认模型 |
| **配置深度思考** | `/thinking` | 调优思维链（Reasoning）Token 预算与深度思考参数 |
| **Pro 推理档位** | `/pro on`, `/pro off`, `/pro reset` | 临时强制开启或关闭高算力推理模式 |
| **极速处理档位** | `/fast on`, `/fast off`, `/fast reset` | 开启或关闭服务商支持的超快响应档位 |
| **查看执行环境** | `/environment` | 检查当前沙箱隔离级别与目录挂载状态 |

### 输入、显示与状态

- **实时引导生成（Steer）：** 当 Agent 正在思考或生成代码时，直接键入补充要求并回车（或使用 `/steer <消息>`）。Harness 会在保留此前有效生成的基础上，将指引注入下一步决策中。
- **深度检查工具详情：** 按下 **Ctrl+O** 可在简洁模式与全量诊断视图之间无缝切换，随时查看原始命令入参、执行返回值及语法高亮 Diff。
- **保护未发送草稿：** 若您意外关闭编辑器或临时取消操作，输入草稿会被妥善暂存在缓冲区。输入 `/recover` 即可找回暂存草稿。
- **命令与技能补全：** 按下 **Tab** 键自动补全斜杠命令、可用模型及已注册的技能包；输入 `$` 字符即可唤起 Skill 技能选择面板。

### 审批与提问

当 Agent 尝试执行敏感命令或需要您确认业务逻辑时，会展示交互式决策卡片：

1. 审查工具名称、调用入参以及可视化的安全风险级别。
2. 使用上下方向键选择 **Approve once（单次批准）**、**Deny（拒绝）** 或 **Deny with reason（说明理由拒绝）**。
3. 若选择提供理由，输入反馈后回车，Agent 会根据您的意见立即调整方案。

#### 回答问题

当 Agent 发起交互式单选或多选题卡片时：

1. 使用 **Up/Down** 方向键切换聚焦的高亮选项。
2. 对于多选题，按下 **Space（空格键）** 勾选或取消选项，确认完毕后按 **Enter** 提交。
3. 如需自由补充个性化输入，按 **Tab** 键切换至自定义文本输入框，输入完成后按 **Enter** 提交。

### 主题、滚动、粘贴与附件

Harness UI 原生支持在终端中直接挂载文件与多媒体附件：

1. 输入 `/attach "path/to/screenshot.png"` 或 `/attach "docs/notes.md"`。
2. 等待附件占位符（如 `[image#1]`）在输入框中渲染就绪。
3. 在占位符后补充提示词并回车发送。

如需挂载剪贴板中的截图，直接按下 **Ctrl+V** 或输入 `/paste-image` 即可一键粘贴。

| 交互功能 | 快捷键 / 命令 | 说明 |
| :--- | :--- | :--- |
| **主题色彩切换** | `/theme auto`, `/theme dark`, `/theme light` | 自适应或调整配色以完美贴合您的终端色彩方案 |
| **历史输出滚动** | **PageUp** / **PageDown** | 平滑翻页浏览历史输出记录 |
| **跳转至最新流** | **Ctrl+End** | 瞬间回到终端底部实时追踪正在生成的最新输出 |
| **鼠标模式切换** | `/mouse on`, `/mouse off` | 自由切换鼠标滚轮控制面板 vs 原生终端鼠标文本划选复制 |

### 长粘贴文本与 Thread 工作文件

当一次性粘贴超过 1,000 个字符的长文本时，Harness UI 会自动将其折叠为紧凑的标记占位符。将光标移动至标记上按下 **Alt+E**，即可展开查看或编辑完整文本块。

每个对话线程在底层分配了独立的专属工作目录，用以存放附件与执行产物：

| 目录路径 | 生命周期 | 存储内容 |
| :--- | :--- | :--- |
| `attachments/` | 跨轮次持久保存 | 用户提交并挂载的文件与截图 |
| `tmp/` | 跨轮次复用 | 编译构建生成的中间产物与下载数据 |
| `tmp/tool-results/` | 单次运行结束后自动清理 | 超大规模的工具原始输出日志与临时转储文件 |

### 查找已保存对话

浏览并恢复历史会话记录：

1. 在 TUI 中输入 `/resume`。
2. 使用 **Up/Down** 上下翻阅历史会话列表，右侧面板会展示历史关键片段预览。
3. 选中后按下 **Enter** 即可加载该对话并立即接续。

| `/resume` 界面快捷键 | 操作说明 |
| :--- | :--- |
| **Up / Down** | 浏览历史对话条目 |
| **PageUp / PageDown** | 跨页翻阅历史列表 |
| **Ctrl+A** | 切换是否包含跨项目及未归属项目的历史会话 |
| **F2** | 重命名当前选中的会话标签 |
| **Escape** | 关闭历史选择面板，返回当前输入草稿 |

### 查看保留历史

按下 **Ctrl+T** 或输入 `/history` 打开全屏会话回放器。使用 **PageUp** 与 **PageDown** 翻阅历史轮次，按下 **Escape** 随时退出回放面板。

### 任务、用量与终端反馈

随时查询系统状态与实时统计指标，即使 Agent 正在生成中也能即时响应：

| 查询目标 | 命令 | 获取的信息 |
| :--- | :--- | :--- |
| **系统状态** | `/status` | 当前活跃 Agent、Model、工程工作路径及待处理审批 |
| **子智能体状态** | `/subagents` | 已调度的 Subagent 运行状态与返回结果 |
| **后台进程列表** | `/ps` | 当前会话中正在后台运行的 Shell 进程与守护程序 |
| **Token 用量统计** | `/usage` | 累计消耗的 Prompt/Completion Token 及估算费用 |
| **用量明细** | `/usage details` | 按轮次细分的 Token 开销与具体模型计费 |

在生成过程中按下 **Ctrl+C** 可优雅终止当前计算；在空输入框中按下 **Ctrl+D** 或输入 `/exit` 即可退出工作台。

### 任务与笔记

按下 **F2** 快捷键可随时展开或折叠右侧任务看板。看板实时同步展示待办事项、正在进行的任务以及已完成清单。输入 `/notes` 可随时检索 Agent 记录的项目长期备忘。

### 围绕 Goal 持续工作

当面对复杂的复合工程目标（如重构代码、运行自动化测试、排查编译报错并反复修复直到通过）时，推荐开启 Goal 目标模式：

```text
/goal 重构数据库连接池模块，完整运行单元测试套件并修复所有回归问题。
```

在 Goal 模式下，Agent 会自动展开多轮自我驱动循环，反复修改并比对测试结果。顶部进度条会直观展示当前的迭代轮次。当目标确认全部达成后，Agent 会汇报完成结论；如遇外部不可抗阻碍，也会主动列明阻碍因素供您介入。

### 本地宿主机命令

若需在项目目录下快速运行一条本地 Shell 命令而无需经过大模型消耗 Token，只需在命令前加上感叹号：

```bash
!git status
!cargo test
```

命令会直接在本地宿主机环境中秒级执行，输出结果直观回显在终端面板中。

### 工具开关

您可以通过编辑项目根目录下的配置文件，声明式定制内置工具的行为：

```yaml
tools:
  enable_ask_user_question: true
  interaction_timeout_seconds: 120
  enable_codeact: true
```

保存后执行 `a13n-harness-ui config validate` 检验语法。CodeAct 与主动提问功能默认全部开启，以提供最流畅的互动开发体验。
