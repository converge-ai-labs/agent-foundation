<best-practices>
On process-capable mounts, pass the live execution ID as `process_id` to the available Shell controls. Live Shell controls end at execution settlement; a Host-held execution's final result is retrieved through the Host's execution-result tool.

Treat `exec-*` and `process-*` references as opaque. Never invent or alter them or use them as native process IDs. An `exec-*` Shell reference remains controllable across Runs of the same Thread while the same Host runtime retains it and the current Environment authorizes the original target and actions. A `process-*` reference belongs to its originating Run and does not remain usable in continuation Runs. Native discovery can find commands the Provider actually retained after scope loss; a saved reference alone does not restore authority. </best-practices>
