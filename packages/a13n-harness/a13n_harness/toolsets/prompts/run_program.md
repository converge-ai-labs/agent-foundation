Run a reusable CodeAct Python program from the current Environment workspace.

The file must be strict UTF-8, end in .codeact.py, and define exactly `async def main(inputs)`. Keep the main workflow inside main. Monty-supported module initialization, dataclasses, helper declarations, and annotations are allowed; initialization runs on every invocation under the same tool policy and limits. Source is read through the current Environment FileOperator on every call. Each invocation uses a fresh interpreter, receives the inputs mapping (empty when omitted), and returns main's result. It cannot see inline Python bindings, but can use the same explicit store/load values when those tools are listed.
