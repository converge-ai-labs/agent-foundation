<best-practices>
Check the current Environment context before relying on paths. Establish the shell dialect before using platform-specific syntax; a mount name or path spelling is not evidence of the operating system.

Shell and process tools select one Environment mount and cannot perform cross-mount file operations. SDK-text output may be partial, and null producer counts mean unknown. At an observation cap, use application log files; waiting or querying cannot reset the budget. </best-practices>
