# Connections

Use `list_connections` and `get_connection` to read non-secret settings, readiness and version. `create_connection` takes `type`, `name`, typed `configuration`, `auth` and, for a connector, `connector_provider_id`. MCP configuration contains its URL, tool selection, header names and OAuth client settings; connector configuration names an app and action selection. Credentials, client secrets and connector-specific setup values are never model arguments.

`update_connection` takes `connection_id`, the observed `expected_version` and only intended non-secret changes. Omitted settings and credentials survive. Changing the server, authentication binding or app can invalidate authorization under the existing resource rules. Check the returned readiness after every change. `revoke_connection` returns local state and the remote revocation outcome; do not infer that upstream access ended when it reports failure or skipped work.

When creation or an update returns `setup_required`, direct the user to the existing Connections page; this Host does not collect secrets or start browser OAuth on the Agent's behalf. Creation that needs provider-specific setup returns the non-secret proposal and no resource ID; no partial connection was saved. After the user completes setup, reread the connection. Never report authorization success without observed evidence.

For connector accounts, use `list_connector_apps`, `get_connector_app`, `list_connector_actions`, `search_connector_actions` and `get_connector_action_definition`. For MCP servers, use `list_mcp_servers`, `list_connection_tools`, `search_connection_tools` and `get_connection_tool_definition`. Select only returned names. Discovery does not authorize invocation. Definition fragments retain source scope and version; partial schemas are not complete invocation contracts.

MCP `configuration.object_ref_tools` selects Object Reference Transport by original tool name: `{"*_upload": true, "text_upload": false}` enables upload tools except that exact tool, and `{"*": true}` enables all. `*` matches zero or more characters anywhere; other characters are literal and matching is case-sensitive. Exact names win, then patterns with more literal characters; equally specific patterns prefer false, independently of order. A matching rule overrides native metadata; unmatched tools retain native declarations, defaulting to unsupported. Use only for tools whose string arguments accept base64; the Agent supplies scoped object references and runtime performs substitution after ordinary dispatch checks.

MCP `configuration.on_error` is `raise` by default; `skip` omits an unavailable server's tools for the current logical Run and informs the model. Initialization makes at most three attempts for transient failures with 1s/2s backoff. Host authorization and credential preparation still fail, and business calls are never replayed by startup recovery. Changing startup policy preserves the credential.

`test_connection` can call an external service and requires write-effect review. Unknown outcomes must be reconciled, not automatically repeated. Saved `forward_context_headers` controls the connection's ordinary context forwarding together with deployment policy; it never overrides configured credentials or permits secret input.
