# Harness UI Operations

Use this index to find the guidance for the current task. Harness references are grouped by Toolset and may describe tools absent from this Run. Read referenced files through the ordinary `view` tool. Read only the relevant files; an incomplete read should continue from its returned line boundary. Keep essential rules already supplied in the Run's instructions in force.

The current tool schemas, CodeAct catalog, Environment mount table, available subagents, and captured Thread selections define this Run's actual surface. Reference files describe operation; they do not enable tools, grant permissions, select a mount, or replace runtime facts. Templates for dynamic tools use illustrative placeholders; use the actual names and roster supplied in the current Run.

Configuration tasks use the separate `harness-ui-configuration` Skill. This bundle contains this installed release's guidance and requires no network access.
