# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to [support@converge.ai](mailto:support@converge.ai) with the subject "Agent Foundation security report".

Do not disclose vulnerability details in public issues or pull requests. For ordinary bugs and feature requests, use [GitHub Issues](https://github.com/converge-ai-labs/agent-foundation/issues).

Include the affected component and version or commit, reproduction steps, and potential impact. Do not include credentials, personal data, or other sensitive information unless necessary; contact us first to arrange how to share it.
