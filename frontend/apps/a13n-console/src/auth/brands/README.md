# Sign-in marks

The Console bundles these assets so opening the login page never sends a brand-image request to an identity provider or CDN.

- `google.png`: the [full-color G](https://developers.google.com/static/identity/images/g-logo.png) from Google's [sign-in branding guidelines](https://developers.google.com/identity/branding-guidelines).
- `microsoft.svg`: the [four-square symbol](https://learn.microsoft.com/en-us/entra/identity-platform/media/howto-add-branding-in-apps/ms-symbollockup_mssymbol_19.svg) from Microsoft's [sign-in branding guidelines](https://learn.microsoft.com/en-us/entra/identity-platform/howto-add-branding-in-apps).

The artwork is unchanged. The marks remain subject to their owners' trademark terms.
