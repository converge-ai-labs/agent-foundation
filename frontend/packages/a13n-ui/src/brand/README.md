# Brand assets

`SpaceGrotesk-Bold.woff2` is the unmodified Space Grotesk Bold font from [Florian Karsten Studio](https://github.com/floriankarsten/space-grotesk), revision `03507d024a01282884232081fc6011c09ff4e849`, at `fonts/woff2/static/SpaceGrotesk-Bold.woff2`. Its SIL Open Font License is included in `SpaceGrotesk-OFL.txt`.

Use `Wordmark` for the a13n brand name and `Logo` for its symbol. `LogoAnimation` is a decorative looping form of the symbol: it turns 60° per cycle while its shadow follows slightly behind, and reduced-motion preferences leave it still. Callers that show it for loading supply their own status text. `--a13n-font-brand` exposes the brand typeface for other brand typography. Applications control scale and placement; the shared wordmark owns weight and spacing. `a13n-ui/brand/mark` exports the symbol's geometry and colors for surfaces that draw it without React.

Use `BrandIcon` for product and provider identities shared across applications. It resolves canonical identities, aliases, and exact endpoint hosts through the exported `brands` registry, supports light and dark variants, and tries the resolved brand, a caller-provided HTTPS logo, and an optional `fallbackIdentity` in order. If none loads, it shows a generic icon. The registry is display-only and never selects endpoints or accounts.

`typesafe.svg` preserves the inline vector symbol published on [TypeSafe's website](https://typesafe.ai/), retrieved on September 30, 2026. The source SVG's DOM ID and overflow attribute are omitted, the SVG namespace is added for standalone rendering, and its white fill is changed to black for light backgrounds; `BrandIcon` inverts it in dark mode. The mark remains subject to its owner's trademark terms. TinyFish uses its vendor-hosted favicon, an SVG containing the vendor's PNG mark.

`boxd.svg` preserves the geometry of [boxd's official favicon](https://boxd.sh/favicon.svg). Its near-white fill is inverted for light backgrounds; dark mode restores the original color.

The registry includes the complete LobeHub Icons catalog through version-pinned jsDelivr URLs. Console sign-in uses bundled SVGs through `BrandIcon` in `bundledOnly` mode, without contacting a CDN or using provider-supplied URLs. `google.svg` contains the Google G from `@lobehub/icons-static-svg@1.95.0` (`icons/google-color.svg`); `microsoft.svg` is the [four-square symbol from Microsoft's sign-in branding guide](https://learn.microsoft.com/en-us/entra/identity-platform/howto-add-branding-in-apps). `lobe-brands.generated.ts` records the generated mappings from `@lobehub/icons@5.18.0` to `@lobehub/icons-static-svg@1.95.0`. Run `pnpm --dir frontend --filter a13n-ui sync:brands` after updating the pinned versions in the generator, then review and test the generated diff. LobeHub Icons is distributed under the MIT License.

`auth0.svg`, `authelia.svg`, `authentik.svg`, `cloudflare.svg`, `github.svg`, `gitlab.svg`, `keycloak.svg`, and `okta.svg` are monochrome marks from [`simple-icons@15.21.0`](https://github.com/simple-icons/simple-icons/tree/15.21.0/icons) (CC0). `BrandIcon` inverts these marks for dark mode. `zitadel.svg` and `zitadel-dark.svg` preserve the artwork of ZITADEL's official [dark symbol](https://github.com/zitadel/zitadel/blob/v4.16.2/console/src/assets/images/zitadel-logo-solo-dark-icon.svg) for light backgrounds and [light symbol](https://github.com/zitadel/zitadel/blob/v4.16.2/console/src/assets/images/zitadel-logo-solo-light-icon.svg) for dark backgrounds. The SVGs omit only the XML declaration and external DTD. Product and provider marks remain subject to their owners' trademark terms.
